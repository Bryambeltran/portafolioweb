# Portafolio Web — Bryam Beltrán

Portafolio personal desarrollado con HTML, CSS y JavaScript, orientado a presentar proyectos, habilidades y medios de contacto de forma profesional.

**Repositorio:** [github.com/Bryambeltran/portafolioweb](https://github.com/Bryambeltran/portafolioweb y https://teclab.uct.cl/~bbeltran2022/)

---

## Descripción

Sitio web de una sola página (Single Page) que reúne mi perfil como desarrollador, proyectos destacados y un formulario de contacto funcional con backend en PHP.

---

## Tecnologías utilizadas

| Capa | Tecnología |
|------|-----------|
| Estructura | HTML5 |
| Estilos | CSS3 |
| Interactividad | JavaScript (Vanilla) |
| Backend | PHP |

## Secciones

- **Inicio** — Presentación principal

---

## Herramientas de apoyo en el desarrollo

Durante el proceso se utilizaron distintas herramientas para optimizar el flujo de trabajo:

- **Figma** — Creación del wireframe y planificación visual del sitio antes del desarrollo.
- **ChatGPT** — Apoyo en la escritura de código y generación de estructuras base.
- **Claude** — Resolución de problemas más complejos y depuración avanzada.
- **Gemini** — Edición y optimización de imágenes utilizadas en el sitio.

---

## Instalación y uso local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Bryambeltran/portafolioweb.git
   ```

2. Abre `index.html` directamente en el navegador o usa **Live Server** desde VS Code.

3. Para el formulario de contacto, se requiere un servidor local con soporte PHP (XAMPP, WAMP u otro).
